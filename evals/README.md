# Open evaluation set

Labelled ideas for measuring how accurate a screen is: one JSON file per idea in `ideas/` (format
`jevscreen.eval/1`). How the files look, how labels are made (official filings only, never TradingView / Yahoo
text) and how to score a run: [docs/EVAL.md](../docs/EVAL.md).

The set is being built. Until the first ideas land here, `jevscreen eval check` reports "no files".
