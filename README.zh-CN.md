# jev-screen

[English](README.md) · **中文**

**用一句话说出你的投资想法（中文、英文都行），jev-screen 帮你在全球上市公司里找出「年报或公开的公司简介里写明在做这件事」的公司，排好序，每家都附上原文证据。**

它在你自己的电脑上运行，由 AI 模型（Jev）替你读材料。每个想法大约花几毛美元，通过 TypeSafe 官方 API、OpenRouter 或 Vercel AI Gateway 付费，你有哪家的账号就用哪家，价格一样。它给的是研究起点，不是投资建议。

**先说实测结果：** 不做任何校准时，前 40 名里平均约 1/4 明显对、约 1/3 明显错；供应链类和东南亚类的想法更差（[详细](#准不准局限在哪)）。请把它当成初筛名单，先看带「年报原文」标签的行，它们比「只有简介」的行可靠得多。

## 30 秒看懂

你对自己的 AI 助手说：

> 找做企业 AI agent 身份与权限管控的公司。

第一次大约 15 分钟后（以后每个新想法约 4 分钟），AI 会在聊天里回复你，浏览器里同时打开一个结果页。下面的公司是占位的，因为真实结果会引用只限个人使用的年报和简介原文；家数、花费和用时是第一次运行的典型数值。

```text
完成：34 家入选（年报确认 21，只有简介 13）。花费 $0.31（约 ¥2），用时 12 分钟。结果页：已在浏览器打开。仅供你个人研究，请勿分享。

1. 公司 A（NASDAQ:AAAA，美国）——面向人和机器账号的身份安全；明确符合，年报原文
2. 公司 B（TSE:0000，日本）——特权访问管理软件；明确符合，年报原文
3. 公司 C（SZSE:000000，中国）——企业零信任访问网关；相关，只有简介
……
```

结果页上每一行都带证据，并且把四种话分开写：

| 标签 | 是什么 |
|---|---|
| **事实** | 公司最新年报里的原文（附申报日期和原文链接）；拿不到年报时是公司简介 |
| **推断** | AI 的判断：「明确符合」（原文直接写了）或「相关」（沾边，或只是业务的一部分） |
| **缺口** | 缺了什么：没有年报、年报太旧、公司连简介都没有 |
| **你的判断** | 你在校准卡上的回答（见下文） |

名单下面还有三部分：通过了第一轮快速阅读、但没能核实的公司（**未核实**），数据缺口，以及最多 8 张卡。结果页是一个本地 HTML 文件，打开时不联网，整页都是你的语言（中文或英文）；外文的简介和年报摘录由你自己的 AI 翻译，标着「AI 翻译」，点一下就能看原文。

**它怎么做的，五步：**

1. 在本地建一份全球上市公司清单，每家公司只算一个主要上市代码，带市值。SPAC 这类空壳公司会被剔除，A 股的 ST / \*ST 会标出来。
2. AI 把每家公司的简介读一遍，判断它现在的主业跟你的想法对不对得上。这是第一轮快速阅读，只读简介。
3. 通过的公司，去官方网站免费取它最新的年报（[哪些市场有年报](#哪些市场能用年报核对)），AI 再读年报摘录核对一次。
4. 排序：同样的判断，年报确认的权重是只凭简介的两倍，再加上模型的把握程度。
5. 生成结果页和校准卡。想知道「X 为什么（不）在名单里」，可以用 `jevscreen why`。

### 关于 Jev 这个模型

背后的 AI 叫 **Jev** 1.13，由 [TypeSafe](https://docs.typesafe.ai) 开发，项目名就来自它。

- **在哪儿买：** Jev 可以通过 TypeSafe 官方 API、OpenRouter 或 Vercel AI Gateway 使用，价格一样：每百万输入 token $0.042，输出免费。有一家的账号就够了，你最后设置的是哪家的 key，它就用哪家。

  | 渠道 | jev-screen 发送的模型 id | 版本 | 设置 key |
  |---|---|---|---|
  | [TypeSafe 官方 API](https://console.typesafe.ai/keys)（官方注册有时会暂停） | `jev-1.13.0` | 固定版本 | `jevscreen keys set typesafe` |
  | [OpenRouter](https://openrouter.ai/settings/keys) | `typesafe/jev-1.13` | 固定在 1.13 | `jevscreen keys set openrouter` |
  | [Vercel AI Gateway](https://vercel.com/docs/ai-gateway/sdks-and-apis/typesafe) | `typesafe-ai/jev` | 不固定：Vercel 只提供这个不带版本号的 id | `jevscreen keys set vercel` |

  设了好几家的 key 时，用最后设置的那一家；想换回另一家，运行 `jevscreen keys use typesafe|openrouter|vercel`（不用重新输 key），不要的 key 用 `jevscreen keys clear <渠道>` 删掉。AI 的回答按渠道分别缓存，换渠道后会重新读一遍（再付一次费），换的时候会告诉你之前在原渠道花了多少。
- **为什么用它：** 它做选择题时会给出每个选项的概率，而且便宜。把约 2 万家公司的简介读一遍，实测约 $0.71。有了概率，就能按把握程度排序，并对分界线附近的公司多读几次。
- **钱付给谁：** 你用自己的 key 直接付给你选的那家。代码不附带任何推荐码、返佣码或应用标识。
- **隐私：** 如果你的想法比较敏感，先看一下那家的数据设置，比如 OpenRouter 的[隐私设置](https://openrouter.ai/settings/privacy)，或 Vercel AI Gateway 的[数据说明](https://vercel.com/docs/ai-gateway/faq)。

## 让你的 AI 帮你装，大约 15 分钟开始

**你需要：**

- **一个 AI 编程助手**，能在你电脑上执行命令，比如 Claude Code、Codex、Cursor。它通常要单独付费，这部分不属于 jev-screen。
- **macOS 或 Linux。** 暂不支持 Windows：没有测试过，也没有隐藏输入框。WSL（Windows 里的 Linux）也许能用，同样没有测试过。
- **能访问这些网站的网络：** github.com 和 raw.githubusercontent.com（或 cdn.jsdelivr.net）、你的 Jev 渠道（api.typesafe.ai、openrouter.ai 或 ai-gateway.vercel.sh）、tradingview.com，以及各地的官方披露网站。在中国大陆，其中好几个经常很慢或打不开，第一步下载就可能失败。用你平时的网络设置就行。工具和 AI 助手只是不会在被某个网站拒绝后，换网络或换身份去绕过它。
- **一个能付费用 Jev 的账号，并且有余额：** TypeSafe 官方 API、OpenRouter 或 Vercel AI Gateway 任选一家，价格一样。第一次一般要先充值：最低充值额通常是几美元，另有支付手续费，以各家付款页为准；需要能付美元的卡。这笔充值是你第一次真正掏钱；之后每个想法从余额里扣约 $0.25–0.30。还没有账号的话，OpenRouter 最省事；TypeSafe 官方注册有时会暂停；Vercel 上 Jev 可能不在免费额度里。
- **Mac 用户注意：** 第一次用 git 时，可能弹出「安装命令行开发者工具」，点安装即可，要几分钟。如果电脑上既没有 uv，Python 也低于 3.10，AI 会请你先运行一条安装 uv 的命令（uv 会自带合适的 Python）。jev-screen 本身不需要管理员权限。

**对你的 AI 说：**

> 从 https://github.com/YuanTong-Wu/jev-screen 安装 jev-screen，按 AGENTS.md 操作。我的想法是：〈你的想法〉。

AI 会自己装好，然后**只问你一轮问题**，放在一条消息里：

1. **先说一声两个数据源的事，问你可不可以。**
   - 股票清单和公司简介来自 TradingView 和 Yahoo（经 FinanceDatabase），属于灰色用法：人家条款其实不让程序批量拿数据，偶尔可能被限流或暂时封一下。
   - 所以这些数据只留在你电脑上自己研究用，别外传。筛选时从官网（SEC、巨潮、BSE 等）下的年报也一样，自己用。
   - 公司简介和年报摘录会发给 Jev 读一下（[哪些东西会离开你的电脑](#哪些东西会离开你的电脑)）。
   - 你说不要，它就停下，因为没有股票清单就没法筛。
2. **花费上限，默认 $1。** AI 会给你看要发给模型的那句英文，以及预计花费（约 $0.30）。上限是硬的，快超了就停，不会多花。超过 $1 必须你明确同意那个数字。
3. **你有哪一家的 Jev 账号**（还没设过 key 时才问）：TypeSafe 官方 API（[创建 key](https://console.typesafe.ai/keys)）、OpenRouter（[创建 key](https://openrouter.ai/settings/keys)）或 Vercel AI Gateway（Vercel 后台的 AI Gateway API Keys 页面）。AI 会给你每家的注册链接和创建 key 的步骤。key 就像一张付费卡的密码：你的屏幕上会弹出一个输入框让你粘贴，内容不显示，也不经过聊天。千万别把它发到聊天里。能设额度上限的话，建议设几美元。

接下来依次是：

1. 免费下载，约 1 分钟。你创建密钥的时候就已经开始了。
2. 用约 $0.0001 试一下密钥能不能付费。
3. AI 阅读，约 2 分钟。
4. 免费补取年报，一般约 1 分钟、最多 2–3 分钟；证据有变化的公司会在你的上限内重新核对（最多 $0.05）。
5. 结果页打开。

第一次全程约 15–25 分钟，已经算上注册账号。进度 AI 大约每分钟告诉你一次。

只有情况变了才会再问你：预计花费超过上限、预算用完、发给模型的英文意思要改、或者你的 Jev 渠道说余额不足。另外，出结果时可能附带几个可选问题，只在对你的想法有用时才问（直接说“不用”也行，结果不变）：

- **补公司简介。** 你的想法所在市场如果有很多公司没有简介（中国常见），AI 就读不到它们。补简介免费、在后台跑（中国约 10 分钟），补完只让 AI 读新补的公司并重新排序（几美分，在你的上限内），还是同一个结果页。

- **美股年报**（只在前十名里有美国公司时才问）。从 SEC 网站下载年报时，要按它的访问规则在请求里附上一个名字和邮箱。不用注册账号，只发给 sec.gov，用专门的邮箱也行。不给的话，美股只能按简介判断，准确度更低。
- **台湾年报**（只在前十名里有台湾公司时才问）。要不要从台湾 MOPS 下载年报，默认关闭，因为那个网站声明不欢迎程序自动下载。

[AGENTS.md](AGENTS.md) 是写给 AI 助手的（英文，比较技术），交给你的 AI 照着做就行。所有命令和参数在 [docs/REFERENCE.md](docs/REFERENCE.md)（英文）。

## 花多少钱

jev-screen 本身免费（MIT 协议），没有服务器，也不用注册。下载数据、取年报都免费。Jev 模型的费用从**你自己的** TypeSafe、OpenRouter 或 Vercel AI Gateway 余额里扣（三家价格一样）。

| 做什么 | 花费 | 依据 | 时间 |
|---|---|---|---|
| 第一个想法，用 `quickstart`：市值 10 亿美元以上，约 1 万家公司 | 约 $0.30 | 估算（程序预计 $0.20–0.40） | 第一次 15–25 分钟，含下载和注册 |
| 之后每个新想法 | 约 $0.25 | 估算 | 约 4 分钟，另加最多 2–3 分钟补取年报 |
| 同一个想法用 `quickstart` 再问一次，条件没变 | $0 | 实测（答案有缓存） | 几秒；直接重跑 `screen` 约 1 分钟 |
| 回答校准卡并重新排序 | 约 $0.01–0.03 | 实测每个想法 $0.002–0.027，默认最多 $0.05 | 约 1 分钟 |
| 放宽到市值 2 亿美元以上，约 2 万家（`screen --min-mcap 2e8`） | 约 $0.71 | 实测，所用的库比新装的简介更多 | AI 阅读约 4 分钟 |
| 测试密钥能否付费 | 约 $0.0001 | 实测 | 几秒 |

jev-screen 之外，你还要付 AI 助手的费用和 Jev 渠道的第一次充值（见上文）。

每一次付费请求都在本地记账，付过钱的答案不会再付第二次。唯一的例外是请求中途断了、需要重发，这种情况很少，每次不到 1 美分，也在你的上限之内。加 `--dry-run` 只估算、不花钱。自己直接运行 `jevscreen screen`、不加参数时，用的是程序自己的默认值：上限 $3、市值 2 亿美元以上（约 $0.71）。AI 助手每次都会写明上限和市值。

## 哪些市场能用年报核对

| 核对方式 | 市场 |
|---|---|
| **年报，自动** | A 股（巨潮资讯）；印度（孟买证券交易所 BSE，每次最多 40 家） |
| **年报，需要你同意或设置** | 美股，以及在 SEC 提交 10-K / 20-F 的外国公司（需要给 SEC 名字和邮箱）；韩国（需要你自己的免费 OpenDART 密钥，每次最多 20 家）；台湾（另外同意 MOPS，每次最多 8 家，下载较慢） |
| **日本** | 开放数据包，首个版本发布后自动使用（目前约 1,600 家，每天增加）；或者用你自己的免费 EDINET 密钥运行 `sync-edinet` |
| **只有简介** | 港股、欧洲、英国、加拿大、澳洲、东南亚及其他地区；除非这家公司也在 SEC 提交年报 |

A 股、印度和台湾的年报是 PDF，标准安装里已经带了读 PDF 的组件（`pypdf`）。

## 用了哪些数据，许可是什么

代码是 MIT 协议。**数据不是**：每个来源有自己的条款，MIT 管不到它们。逐个来源的说明见 [DATA_LICENSES.md](DATA_LICENSES.md)（英文）。

| 数据 | 来源 | 级别 | 什么时候用 |
|---|---|---|---|
| 股票清单、市值 | TradingView 选股接口 | 灰色·私用 | 你同意后；约 1 分钟 |
| 公司简介 | FinanceDatabase 打包文件 `equities.bz2`（Yahoo 文本，15 MB，从 GitHub 或 jsDelivr 下载） | 灰色·私用 | 你同意后；约 1 分钟 |
| 补充简介（可选） | TradingView 个股页面（`crawl-descriptions`） | 灰色·私用 | 你同意才做；耗时长 |
| 年报，按需下载 | SEC EDGAR（美国，需要名字和邮箱）、巨潮资讯（A 股）、孟买证券交易所 BSE（印度）、OpenDART（韩国，你的密钥）、MOPS（台湾，另外问你） | 官方·私用 | 只取筛选入围的公司，每次有数量上限 |
| 年报，批量同步（可选） | 同上，另加 EDINET（日本，你的免费密钥），用 `sync-*` 命令 | 官方·私用 | 只在你运行时 |
| 开放数据包 | SEC 股票代码表；日本 EDINET 代码表和「事業の内容」（日本年报里的「业务内容」一节） | 官方·开放 / 日本公共数据许可 PDL 1.0 | 自动，不用密钥 |

- **灰色·私用：** 网上公开，但网站条款限制再利用或程序自动取用（TradingView 明确不允许拿它的数据做算法用途）。只限个人使用，需要你记录同意，本项目和你都不能再分发。「灰色」说的是和网站条款有冲突，不是让你自己去猜的法律灰色地带。
- **官方·私用：** 官方披露文件，但没有授权再分发。只限个人使用：全文留在你的电脑上，只有简短摘录会发给 AI 去读。

### 哪些东西会离开你的电脑

| 什么 | 发给谁 |
|---|---|
| 你写的想法原文、它的英文句子、你回答校准卡后生成的规则句子、公司简介、年报的简短摘录 | 你的 Jev 渠道（TypeSafe、OpenRouter 或 Vercel AI Gateway），以及它背后运行 Jev 的服务商 |
| 下载请求（披露网站能看到你要的是哪些公司） | TradingView；GitHub 或 jsDelivr；各官方披露网站（SEC、巨潮资讯、BSE、DART、MOPS）；开放数据包在 GitHub |
| 你给 SEC 的名字和邮箱 | 只发给 sec.gov，随下载请求一起 |

本项目收不到任何东西，也没有使用统计。你做出来的名单、报告和结果页请自己留着，因为它们来自只限个人使用的数据。以上不构成法律意见。拿不准时，数据就留在自己电脑上。

## 准不准，局限在哪

用 4 个想法实测，每个取前 40 名，共 160 行，分成三类：

- **对：** 证据直接说明这家公司属于这个想法。
- **边缘：** 相关，但证据不足、业务太宽或地域不符。
- **明显错：** 角色不对、业务无关，或只是持股。

「校准后」指回答一轮卡片（6–7 张）之后。

| 想法 | 对 / 边缘 / 错 | 校准后 |
|---|---|---|
| 企业 AI agent 身份与权限管控 | 18 / 13 / 9 | 21 / 14 / 5 |
| GLP-1 多肽的委托生产（CDMO）与给药器械 | 11 / 23 / 6 | 14 / 22 / 4 |
| 人形机器人关节减速器 | 10 / 11 / 19 | 12 / 13 / 15 |
| 东南亚数字支付与电子钱包 | 5 / 16 / 19 | 5 / 23 / 12 |
| **合计（160 行）** | **44 / 63 / 53** | **52 / 72 / 36** |

**怎么测的，你的情况有什么不同：**

- **测试时间：** 2026-09-26，用的是校准卡 v1。这次发布的是 v1.1，其中的修正还没有重新测过。
- **测试条件：** 每个想法的基础筛选都是放宽版（市值 2 亿美元以上，约 2 万家）。用的库批量同步过年报原文（市值 10 亿美元以上约 55% 的公司有，来自 SEC、巨潮资讯、EDINET 和 DART），也补爬过简介。
- **你新装时证据会少一些：** 从市值 10 亿美元起步，用 FinanceDatabase 的简介（10 亿美元以上约 69% 的公司有），年报按需下载。美股要你给 SEC 名字和邮箱，日本靠开放数据包，韩国要 OpenDART 密钥。「只有简介」的行会比测试里多。
- **谁判的：** 由跑测试的 AI 助手逐行看证据判定。减速器和 GLP-1 两题是在试跑时看完整证据判的；AI agent 和东南亚两题是事后看截短到约 260 字的摘录补判的，宽严可能不一致。项目作者人工复核过其中一家。判定不独立、不盲，而且只有 4 个想法，请当作方向参考，不是基准测试。

从这次测试能看出：

- **年报确认的行比只有简介的行可靠得多。** 有美国 10-K 年报支撑的行基本都对。测试里记下的误判为「明确符合」的行，比如支付那一题里的一家加油站零售商，都是只凭简介判的。
- **擅长：** 想法是一个有标准说法的产品类别，而且公司有系统读得到的年报。AI agent 权限那一题，校准后 21 家对、5 家错。
- **不擅长供应链类想法：** 会搞混角色。买方、通用零件商、伺服电机厂、只持股的公司都被当成了供应商。减速器那一题，校准后 40 家里仍有 15 家明显错。
- **不擅长按地域定义的想法：** 印尼、越南、泰国、马来西亚、菲律宾的公司在这里只有简介。东南亚支付那一题「对」始终只有 5 家，智能卡和 POS 刷卡机厂商被当成了支付运营商。
- **覆盖：** 新装好时，市值 10 亿美元以上的公司约 69% 有简介。没有任何简介的公司记为缺口，不参与筛选。年报原文来自入围公司的按需下载，日本来自开放数据包。
- **读数有噪声：** 同一段材料，模型每次给的概率平均相差约 0.04；重跑时，前 40 名里靠近分界线的大约会换掉 2 家。所以分界线附近的公司会读 3 次取平均。
- **校准卡修的是你答过的，不是全部：** 明显错从 53 降到 36，但「对」只从 44 升到 52，因为去掉的错行常被同样弱的公司补上。
- **它不估值、不看股价，也不告诉你买什么。** 排名反映的是证据强弱，不是投资价值。

## 下次怎么用，怎么停，怎么卸载

- **换一个想法：** 在 jev-screen 文件夹里打开你的 AI 助手，说「用 jev-screen 筛：〈新想法〉」。约 $0.25、4 分钟，不用重新下载。
- **看旧结果：** `jevscreen page latest --open` 打开最新的结果页。每次筛选的结果页都在 `data/screens/` 下它自己的文件夹里。
- **中途停止：** 让 AI 助手停下；如果是你自己在终端里运行 `screen`，按 Ctrl-C。已付费的答案都留着，重跑会接着做，上限照样有效。
- **占多少硬盘：** 只走 quickstart 流程，通常远小于 1 GB；把所有数据源都批量同步过的库约 2 GB。
- **卸载：** 删除 jev-screen 文件夹就行，数据、密钥和同意记录都在里面的 `data/` 下。再去你的 Jev 渠道（TypeSafe、OpenRouter 或 Vercel）删除那个密钥。

## 命令一览

一般由你的 AI 替你执行。`quickstart`、`doctor`、`why`、`answer`、`fetch-docs`、`page`、`cards`、`coverage` 和 `sieve` 可以加 `--json` 输出 JSON，其他命令不接受这个参数。主要参数见 [docs/REFERENCE.md](docs/REFERENCE.md)，全部参数用 `jevscreen <命令> --help` 查看；JSON 格式见 [docs/AGENT_API.md](docs/AGENT_API.md)。

| 命令 | 做什么 | 花费 |
|---|---|---|
| `jevscreen quickstart "<想法>" --json` | 从想法到结果页的全流程，只问一轮问题 | 在你同意的上限内 |
| `jevscreen doctor --json` | 装好了什么、缺什么、下一步该跑什么 | 免费 |
| `jevscreen keys set typesafe\|openrouter\|vercel --dialog` / `keys check` | 在屏幕上弹出隐藏输入框保存密钥，从不显示；自己在终端里用 `keys set 名称` | 免费 |
| `jevscreen consent set gray-sources yes\|no` | 记录你对那两个数据源的回答 | 免费 |
| `jevscreen screen "<想法>" --min-mcap 1e9 --budget 1 [--dry-run]` | 可以调所有设置的筛选（国家、市值、读几次） | 付费，预算是硬上限 |
| `jevscreen page latest --open` | 重建并打开结果页 | 免费 |
| `jevscreen why <代码> --run <run_id>` | 某家公司为什么（不）在名单里、怎样才会变 | 免费 |
| `jevscreen answer "1a 2h 3c" --deck <deck>` | 应用你对校准卡的回答，重新排序 | 约 $0.01–0.03 |
| `jevscreen fetch-docs latest` | 给某次筛选的入围公司补取年报并更新结果 | 取年报免费，更新最多 $0.05 |
| `jevscreen sieve add should_pass <代码> --run <run_id>` | 你认为应该有的公司，下次筛选时核对并报告 | 免费 |
| `jevscreen pack pull` | 导入开放数据包 | 免费 |
| `jevscreen status` / `coverage` | 数据行数；按地区、来源、许可级别看缺口 | 免费 |
| `jevscreen refresh-universe`、`crawl-descriptions`、`sync-sec` / `-cninfo` / `-edinet` / `-dart` / `-mops` / `-bse`（`-bse` 是印度孟买交易所） | 手动同步数据 | 免费；有的要几个小时 |
| `jevscreen import-fd` | 从本地的 FinanceDatabase DuckDB 文件导入简介；用 quickstart 不需要，它会自己下载 | 免费 |

## 校准卡

AI 读材料，犯的错来来回回就那几种：把买方当成供应商、字面对上了意思却不同、把一句规划当成了业务。你的想法边界在哪里，只有你知道。所以每次筛完，结果页会给你最多 8 张**卡**。每张卡是一家靠近分界线的公司，附一小段证据原文（和你的想法关键词最贴近的那段）。

在结果页上点「要」或「不要」，愿意的话再点一个理由（比如「是买方，不是供应商」）。结果页会拼出一行命令，比如 `jevscreen answer "1a 2h 3c" --deck deck-...`，把它复制给你的 AI 就行，约 $0.01–0.03。你的回答会记住，名单不用重读简介就会重新排序，下次筛同一个想法也会用上。上面的实测里，这一步把明显错从 53 行降到 36 行；但数据里没有的「对」，它变不出来。

机制细节（理由字母 a–k、回答怎样变成规则、关键词学习）见 [docs/DATA_RULES.md](docs/DATA_RULES.md) 的 "Calibration" 一节；回答的写法见 [docs/REFERENCE.md](docs/REFERENCE.md#commands) 里 `answer` 那一行；你的 AI 可以在这个想法的筛选设置文件里写什么，见 [docs/SIEVE.md](docs/SIEVE.md)。

## 开放数据包

一个每天发布一次的免费数据包，作为本仓库的 GitHub Releases 发布（`pack-YYYY-MM-DD`），只收许可允许再分发的数据：

- SEC 股票代码表；
- 日本的 EDINET 代码表，以及上市公司最新有価証券報告書（日本的年度证券报告）里的「事業の内容」（业务内容）一节，用日本公共数据许可 PDL 1.0，附出处。目前约 1,600 家，每天增加。

首个版本发布后，`quickstart` 会自动拉取，日本公司不用 EDINET 密钥也能用自己的年报核对；在那之前，日本公司先用简介。

手动导入用 `jevscreen pack pull`，每个文件都会校验完整性。包里没有任何 TradingView 或 Yahoo 的数据，也没有别的年报原文。

有一点尚未确认：公司自己写的「事業の内容」是否在 EDINET 许可范围内，数据包里已写明这一点。详见 [docs/OPEN_PACK.md](docs/OPEN_PACK.md)。

## 常见问题

**这是投资建议吗？** 不是。它只找出年报或简介跟你的想法对得上的公司，并给出证据；不估值、不择时、不推荐。做任何决定前，请自己看原始文件。

**哪些东西会离开我的电脑，谁能看到？** 见[上面的表](#哪些东西会离开你的电脑)。简单说：

- 你的想法原文和英文句子、规则句子、公司简介、年报简短摘录，会发给你的 Jev 渠道（TypeSafe、OpenRouter 或 Vercel AI Gateway）和它背后运行 Jev 的服务商。
- 下载请求会发给各数据网站。
- 你给 SEC 的名字和邮箱只发给 sec.gov。

密钥存在 `data/` 里，只有你的电脑账号能读，从不显示。

**名单或结果页能分享吗？** 用默认数据源做出来的不能，因为它们来自只限个人使用的数据。可以分享的是代码、你的想法，以及只用开放数据包做出来的东西。[DATA_LICENSES.md](DATA_LICENSES.md) 和 [docs/DATA_RULES.md](docs/DATA_RULES.md) 里是同一条规则。

**为什么 X 不在名单里（或者为什么在）？** 问你的 AI。它会运行 `jevscreen why X --run <run_id>`（免费），用一句话告诉你 X 停在哪一步（市值、没有简介、第一轮阅读、年报核对还是排名），以及怎样才会变。你确定 X 应该在，就把它加成检查项（`sieve add should_pass`），或者在它的卡上回答。

**不用 TradingView 和 Yahoo 的数据行不行？** 不行。目前没有一份免费、许可干净、带业务描述的全球股票清单可以替代；开放数据包只覆盖美股代码和日本。你不同意使用这些来源，jev-screen 就停下，不会再问。
